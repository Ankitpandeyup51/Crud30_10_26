# 🚀 Crud30_10_26 – ASP.NET MVC CRUD Application


## 📌 About Project

Crud30_10_26 is a web-based CRUD application developed using ASP.NET MVC, C#, ADO.NET, and SQL Server. It allows users to manage records through Create, Read, Update, and Delete operations.

## ✨ Features

- User Registration & Login
- Insert New Records
- View Records
- Update Records
- Delete Records
- SQL Server Database Connectivity
- User-Friendly Interface

## 🛠️ Technologies Used

- C#
- ASP.NET MVC
- ADO.NET
- SQL Server
- HTML5 & CSS3
- Bootstrap
- JavaScript
- Visual Studio

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Ankitpandeyup51/Crud30_10_26.git
```

2. Open the project in Visual Studio.
3. Configure the SQL Server connection string in `Web.config`.
4. Create the required database and tables.
5. Build and run the application.

- CRUD Operations
